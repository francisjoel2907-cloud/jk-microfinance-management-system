# 🏦 JK Microfinance Management System

A full-stack, enterprise-grade microfinance management platform designed to streamline loan applications, customer tracking, repayment schedules, automated penalty calculations, and financial reporting.

## ✨ Key Features

- **🔐 Authentication & Role-Based Access Control:** Secure JWT authentication with granular permissions for Admins, Loan Officers, and Management.
- **👥 Customer Management:** Complete client profiles, document attachments, credit history, and custom statement generation.
- **💰 Loan Lifecycle Management:** Loan creation, flexible installment plans, approval workflows, and active balance tracking.
- **📈 Repayment & Penalty Automation:** Track daily/weekly repayments, automatically account for overdue installments, and apply penalties.
- **📊 Interactive Dashboard & Reports:** Visual analytics on portfolio health, collection charts, and exportable PDF financial reports.

## 🛠 Tech Stack

### Frontend
- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Shadcn UI
- **Icons:** Lucide React

### Backend
- **Runtime:** Node.js + Express.js
- **Language:** TypeScript
- **Database ORM:** Prisma
- **Database:** PostgreSQL
- **PDF Generation:** PDFKit / Client-side PDF generators
